# Lead API

`POST /api/lead` is implemented in the Node.js runtime. The page is still a
placeholder; F4 will connect the shared visitor form. F3 will deliver the pending
notification jobs; this endpoint currently makes no Telegram call.

## Request

Use `Content-Type: application/json` (an optional charset is accepted).
The actual body stream is limited to 16 KiB regardless of `Content-Length`.
The root and attribution objects reject unknown keys, arrays, and null.

```json
{
  "name": "Анна",
  "phone": "+375 (29) 123-45-67",
  "interest": "one-time",
  "comment": "Подскажите помол для фильтра.",
  "productId": "brazil-cerrado",
  "attribution": {
    "utm_source": "instagram",
    "utm_campaign": "autumn",
    "utm_content": "coffee-bag",
    "landingUrl": "https://kvarta.example/?utm_source=instagram",
    "referrer": "https://example.com/ad"
  }
}
```

This is synthetic example data. Run local migrations before trying the endpoint.

| Field | Validation |
| --- | --- |
| `name` | Required string, at most 100 characters before trimming, nonblank after trimming. |
| `phone` | Required string, at most 64 characters before trimming; valid Belarusian number with whole-input `libphonenumber-js/max` parsing, default country BY. Extensions rejected; stored as E.164. |
| `interest` | Required: `subscription`, `one-time`, or `question`. |
| `comment` | Optional string, at most 2,000 characters before trimming; ordinary line breaks/tabs allowed. Blank becomes SQL null. |
| `productId` | Optional identifier from the list below; absent becomes SQL null. |
| `attribution` | Optional strict object; absent becomes `{}`. All contained values are optional strings; blanks are omitted. |

Control characters are rejected in single-line fields; comments permit tab,
carriage return, and line feed but reject other control characters. Limits count
Unicode code points, as defined by the installed Zod version. The body byte limit
also applies, so a collection of individually valid long fields can exceed it.

Product IDs: `ethiopia-yirgacheffe`, `colombia-huila`, `brazil-cerrado`,
`drip-assortment`, and `subscription`. Individual products require `one-time` or
`question` interest; `subscription` context requires `subscription` or `question`.
Product context may be omitted for any valid interest.

Attribution keys:

- Up to 256 characters each: `utm_source`, `utm_medium`, `utm_campaign`,
  `utm_term`, `utm_content`, `utm_id`.
- Up to 512 each: `gclid`, `fbclid`, `yclid`.
- Up to 2,048 each: `landingUrl`, `referrer`; absolute HTTP(S) URL with no username
  or password. Validated values are stored, never fetched.

The endpoint saves the supplied attribution. F4 will capture the entry page and
available referrer in the browser; the API request URL is not a substitute for
the landing URL. Missing attribution is allowed and is not fabricated.

## Responses

All responses generated by this POST handler are JSON with `Cache-Control: no-store`.
No response includes contact details, existing lead ID, or duplicate timestamp.

| HTTP | Body fields | Meaning |
| --- | --- | --- |
| 201 | `ok: true`, `status: "saved"`, `message` | Lead and one pending job committed. |
| 200 | `ok: true`, `status: "duplicate"`, `message` | A lead for the normalized phone was accepted less than ten minutes ago. No write. |
| 400 | `ok: false`, `status: "invalid"`, `message`, `fieldErrors` | Invalid fields/schema; correct the indicated fields. |
| 400 | `ok: false`, `status: "error"`, `code: "invalid_json"`, `message` | Malformed JSON, invalid UTF-8, or unreadable body. |
| 413 | `ok: false`, `status: "error"`, `code: "body_too_large"`, `message` | Body exceeds 16 KiB; shorten it. |
| 415 | `ok: false`, `status: "error"`, `code: "unsupported_media_type"`, `message` | Use JSON content type. |
| 503 | `ok: false`, `status: "error"`, `code: "temporarily_unavailable"`, `message` | Storage/transaction failed or timed out; preserve input and retry. |

Messages are in Russian. A field error looks like:

```json
{
  "ok": false,
  "status": "invalid",
  "message": "Проверьте поля формы.",
  "fieldErrors": { "phone": "Укажите действующий белорусский номер." }
}
```

Field paths can include `attribution.landingUrl`; unknown fields use `form` without
echoing their names or values. Unsupported HTTP methods receive Next.js's 405.

## Persistence and retries

The transaction serializes submissions for one normalized phone in PostgreSQL,
samples database time after waiting for that lock, and atomically inserts the
lead and one pending outbox job. The phone can submit again at exactly ten
minutes after its last accepted lead. Duplicate attempts do not extend the window.
Different application instances use the same database coordination.

If a response is lost after commit, retrying the same phone inside the window
returns a duplicate acknowledgement. This also handles an ambiguous connection
failure during commit. Pending jobs survive application restarts; delivery and
recovery are F3 work. The API is not an operator endpoint and returns no stored
lead contents. Current logs contain only a fixed storage-failure category.
